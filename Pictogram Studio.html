Voiceover

Copy the voiceover script gives you the exact words to paste into ElevenLabs. Add the MP3 it makes (or any recording). It plays with the preview and is recorded into the video. Fit scenes to the voice moves each scene change to the nearest pause in the speech. If a cut lands in the wrong place, use Tap out the timing: listen and tap each time the next scene should begin. The voice file is not saved with the project, so add it again after reloading.

Retention check

    These are the checks a computer can make. It cannot tell you whether the hook is interesting. Your retention graph does that.

    Export

    Recording plays the video once in real time, so keep this tab open and visible until it finishes. For a sharper MP4, copy the project text and ask Claude to render it.

    Start from an idea

    Claude picks the format, writes the hook, the scenes, the caption and the timing, using your own Claude usage. It replaces the current scenes. Inside this page Claude cannot look anything up, so it only uses well-known facts and what you paste in. For an idea that needs research and sources, give the idea to Claude in the project chat instead and you get the finished video back.
